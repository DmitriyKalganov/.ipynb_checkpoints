# Магазин кормов для животных

Простая демонстрационная страница для продажи кормов. Откройте `index.html` в браузере, чтобы увидеть лендинг.

На главной странице нажмите кнопку **«Каталог»**, чтобы открыть всплывающее окно со списком товаров. У каждого товара есть кнопка **«Заказать»**, которая открывает окно выбора количества.
